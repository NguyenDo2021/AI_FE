Đã so sánh trực tiếp script trước/sau: toàn bộ script nghiệp vụ của CollectPaymentDialog giữ nguyên sau khi bỏ hai import icon mới. Không đổi API, payload, validation, công thức, quyền/phạm vi kho, state, watcher, handler submit, handler điền số còn lại, idempotency key, khóa request và cơ chế cập nhật đơn sau thu. Giá trị ban đầu vẫn là chuỗi rỗng; số 0 chỉ là placeholder. Tiền tiếp tục dùng formatStockInteger và tiện ích chính xác hiện có; không chuyển qua Number/parseFloat.
